# Event-Hub-Clickable-Prototype
Event Hub is a UI/UX design and prototyping project developed in Figma. The project focuses on creating an intuitive event booking experience through interactive navigation, responsive layouts, and user-friendly interfaces. The prototype includes Login, Home, Event Details, and Registration/Payment screens to simulate a complete user journey.
